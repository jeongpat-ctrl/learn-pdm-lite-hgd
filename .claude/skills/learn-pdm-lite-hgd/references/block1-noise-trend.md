# Block 1: 노이즈 vs 추세

> **Phase A 시작 시 그대로 출력한다:**
> ```
> 📖 공식 문서: 원본 강의 Day5_3_Main_자동차예지보전AI활용.pdf 14쪽 "노이즈인가, 추세인가"
> ```

## EXPLAIN

### 1. 정의

| 용어 | 뜻 |
|---|---|
| 노이즈 | 한 번 튀고 곧 정상으로 돌아오는 일시적 값. 측정 오류·순간 외란일 수 있다 |
| 추세 | 임계선을 향해 꾸준히 오르는 흐름. 이 상승의 시작점이 진짜 정비 신호다 |
| 기준선 상한 | 처음 12점(08:00~11:40)의 평균 + 3 × 표준편차 |
| 추세 시작 | 기준선 상한을 3번 연속 넘은 첫 시각 |

### 2. 왜 이렇게 판정하는가

| 기준 | 평상 범위(평균 ± 2 × 표준편차) | 기준선 + 3번 연속 |
|---|---|---|
| 잡는 것 | 범위를 벗어난 점 | 이어지는 흐름의 시작점 |
| 약한 곳 | 완만한 상승을 놓친다 | 초기 12점이 정상이어야 한다 |
| 쓰임 | 이상 후보 찾기 | 고장 전 계획 정비의 기준점 |

### 3. 케이스 — 프레스 메인모터와 용접로봇 감속기

프레스 메인모터(설비A)는 진동이 한 번 크게 튀고 바로 정상으로 돌아온다. 용접로봇 감속기(설비B)는 온도가 먼저 서서히 오르고 진동이 뒤따른다. 값이 더 큰 쪽이 더 위험한 설비라고 볼 수 있을지 그래프로 확인한다.

## EXECUTE

아래 프롬프트를 붙여 넣으라고 안내한다.

```
pdm-lite-work 폴더의 Day5_설비센서_50건_가상.csv 로 아래를 해 줘. csv는 고치지 마.
1. 설비A·설비B의 진동과 온도를 각각 처음 12점(08:00~11:40) 기준선으로 삼아 상한 = 평균 + 3 × 표준편차 를 구한다.
2. 상한을 3번 연속 넘으면 '추세', 넘었지만 3번 연속이 아니면 '노이즈'로 판정하고, 추세의 첫 시각을 '추세 시작'으로 알려 준다.
3. 설비B의 가장 이른 추세 시작이, 평상 범위(평균 ± 2 × 표준편차)로 처음 잡힌 시각보다 몇 분 빠른지 알려 준다.
4. 같은 시간축에 진동(설비A·B)과 설비B 온도를 그린 그래프 한 장을 index.html 로 만든다. 맨 위에 한 줄 요약, 맨 아래에 '가상 데이터'와 출처를 적고, 휴대폰에서도 가로 스크롤이 없게 한다.
```

### 확인할 것 (Phase B)

- `~/pdm-lite-work/index.html`이 있고 그래프가 한 장 보인다.
- 설비A는 노이즈다: 12:40 진동 3.5 한 점만 상한을 넘는다.
- 설비B 온도 추세 시작은 13:00이다(상한 57.00).
- 설비B 진동 추세 시작은 15:00이다(상한 1.12).
- 평상 범위로 처음 잡힌 15:40보다 160분 빠르다.

숫자가 다르면 "기준선을 처음 12점으로 잡았는지, 3번 연속 조건을 썼는지 확인하고 고쳐 줘"를 붙여 넣게 한다. 정답은 "정답 보기" 요청이 있을 때만 연다.

## QUIZ

```json
AskUserQuestion({
  "questions": [{
    "question": "설비A 진동은 1.0 부근에서 3.5로 한 번 튀고 바로 1.0으로 돌아왔다. 설비B 진동은 1.0→1.3→1.7→2.2→2.9로 올랐고 최고값은 설비A보다 낮다. 계획 정비를 먼저 잡을 설비는?",
    "header": "Quiz 1",
    "options": [
      {"label": "설비A", "description": "최고값 3.5가 가장 높으니 가장 위험하다"},
      {"label": "설비B", "description": "임계선을 향해 꾸준히 오르는 흐름이 신호다"},
      {"label": "둘 다 아님", "description": "3.5를 넘는 값이 또 나올 때까지 지켜본다"}
    ],
    "multiSelect": false
  }]
})
```

정답: 2번. 설비B는 임계선을 향해 꾸준히 오르는 추세적 상승이고, 이 상승의 시작점이 정비 신호다. 설비A를 고르는 것은 "한 번 높았으니 위험"이라는 판단으로, 노이즈와 추세를 혼동한 것이다. 더 높은 값이 나올 때까지 기다리면 고장 전 계획 정비의 기준점을 놓친다. 현장에서는 값의 크기보다 흐름을 먼저 보고, 추세 시작 시각을 정비 시점으로 표시한다.
