# Block 2: 공개

> **Phase A 시작 시 그대로 출력한다:**
> ```
> 📖 공식 문서: https://docs.github.com/ko/pages
> ```

## EXPLAIN

### 1. 정의

| 용어 | 뜻 |
|---|---|
| GitHub Pages | GitHub 저장소의 파일을 웹 주소로 보여 주는 기능 |
| 공개 저장소 | 주소를 아는 누구나 내용을 볼 수 있는 저장소 |

### 2. 공개 전 보안 수칙

- 올리는 파일은 가상 데이터로 만든 `index.html` 하나뿐이다.
- 회사 내부 자료와 비밀번호·토큰은 올리지 않는다.
- GitHub 로그인이 필요하면 비밀번호를 채팅에 적지 말고 브라우저에서 직접 승인한다.

### 3. 왜 공개하는가

| 기준 | 파일로 전달 | 주소로 공유 |
|---|---|---|
| 받는 사람 | 파일을 받아 열어야 한다 | 주소를 누르면 바로 본다 |
| 고친 뒤 | 파일을 다시 보낸다 | 같은 주소에 반영된다 |

## EXECUTE

아래 프롬프트를 붙여 넣으라고 안내한다.

```
pdm-lite-work 의 index.html 을 공개해 줘.
1. GitHub 로그인을 확인하고, 안 되어 있으면 브라우저 로그인용 일회용 코드만 알려 줘. 비밀번호는 묻지 마.
2. index.html 만 들어 있는 공개 저장소 pdm-lite-dashboard 를 내 계정에 만들어 올린다. 같은 이름이 있으면 덮어쓰지 말고 나에게 묻는다.
3. GitHub Pages 를 켠다.
4. 주소가 열리는지 확인해 알려 준다. 몇 분 걸릴 수 있다.
```

### 확인할 것 (Phase B)

- 저장소에 `index.html`만 올라가 있다.
- 알려 준 Pages 주소가 열리고 그래프가 보인다.

주소가 안 열리면 "Pages 배포 상태를 확인하고 원인을 한 줄로 알려 줘"를 붙여 넣게 한다.

## QUIZ

Block 2는 퀴즈가 없다. 확인이 끝나면 대시보드 주소를 짝에게 보내도록 안내하고 수업을 마친다.
