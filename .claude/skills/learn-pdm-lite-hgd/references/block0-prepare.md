## EXPLAIN

### 1. 오늘 쓰는 데이터

| 용어 | 뜻 |
|---|---|
| 다변수 센서 데이터 | 진동·온도·압력처럼 여러 변수를 동시에 시간 순으로 기록한 것 |
| 설비A | 프레스 메인모터 |
| 설비B | 차체 용접로봇 감속기 |

### 2. 왜 폴더를 따로 만드는가

| 기준 | 원본 파일에서 바로 작업 | 작업 폴더에 복사 |
|---|---|---|
| 원본 | 실수로 바뀔 수 있다 | 그대로 남는다 |
| 결과물 | 원본과 섞인다 | 한곳에 모인다 |

## EXECUTE

`{SKILL_DIR}`를 이 스킬 폴더의 실제 경로로 바꿔 아래 프롬프트를 보여 준다.

```
아래 순서대로 해 줘.
1. 내 홈 폴더에 pdm-lite-work 폴더를 만든다.
2. {SKILL_DIR}/assets/lab/Day5_설비센서_50건_가상.csv 를 그 폴더로 복사한다. 원본은 고치지 않는다.
3. 복사한 파일의 행 수와 설비 이름을 확인한다.
4. git, python3, gh 버전과 행 수를 env_check.txt 에 저장하고 한 줄로 알려 준다.
```

- `~/pdm-lite-work/env_check.txt`가 있다.
- 복사한 csv가 50행이고 설비가 설비A·설비B 둘이다.
